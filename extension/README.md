# 🧩 Norma — Quick Capture (Browser Extension)

This extension allows you to capture notes, thoughts, and links from your browser directly to your **Norma** instance with a keyboard shortcut or right-click.

---

### 🚀 How to Install in Chrome / Edge / Brave

1. Open your browser and navigate to:
   * **Chrome**: `chrome://extensions`
   * **Edge**: `edge://extensions`
   * **Brave**: `brave://extensions`
2. In the top right corner, enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `norma/extension` directory from this project.
5. The extension will be loaded and ready to use!

---

### ⚙️ Initial Setup

1. Click the **Norma** icon in your browser toolbar.
2. Click the settings icon (⚙):
   * **Norma URL**: Enter your deployed Norma URL (e.g., `https://norma.vercel.app` or `http://localhost:3000` for local testing).
   * **Personal API Key**: Enter your personal API key copied from your Norma Settings page (starts with `nr_usr_...`).
3. Click **Save**.

---

### ⚡ Everyday Usage

* **Quick Shortcut**: Click the extension icon, write your note, and hit `Ctrl + Enter` (or `Cmd + Enter`).
* **Capture Active Tab**: Click **+ Current Tab** to immediately append the active page title and URL formatted in Markdown.
* **Context Menu (Right-click)**:
  * Highlight any text on a web page &rarr; Right click &rarr; **Save selection to Norma**.
  * Right click anywhere on a page &rarr; **Save current page to Norma**.
